## 🚀 Quick Start

### 1. Download & Extract
Download `NovaDroid_Desktop_v1.0.0_Portable.zip` and extract to any folder.

### 2. Enable USB Debugging on Android
```
Settings → About Phone → Tap "Build Number" 7 times
Settings → Developer Options → Enable "USB Debugging"
```

### 3. Connect Your Device
- **USB:** Connect with USB cable and accept authorization
- **WiFi:** Enable "Wireless Debugging" in Developer Options

### 4. Launch NovaDroid Desktop
Double-click `novadroid_desktop.exe` and enjoy!

## 🔧 Troubleshooting

### "ADB not found" Error
Install Android Platform Tools:
https://developer.android.com/studio/releases/platform-tools

### Device Not Detected
1. Enable USB Debugging on your phone
2. Accept USB debugging authorization dialog
3. Try different USB cable/port
4. Click "Refresh" in Device Manager

### App Won't Start
1. Ensure Windows 10/11 64-bit
2. Check antivirus isn't blocking
3. Run as Administrator
4. Check logs in `%APPDATA%\novadroid_desktop\logs\`
