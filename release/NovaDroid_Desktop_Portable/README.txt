🚀 QUICK START:
═══════════════

1. Double-click "novadroid_desktop.exe" to launch
2. Enable USB Debugging on your Android phone:
   - Settings → About Phone → Tap "Build Number" 7 times
   - Settings → Developer Options → Enable "USB Debugging"
3. Connect your phone via USB or WiFi
4. Enjoy controlling your Android from Windows!

📋 REQUIREMENTS:
════════════════

✓ Windows 10 or 11 (64-bit)
✓ 4GB RAM (8GB recommended)
✓ Android device with USB debugging enabled
✓ USB cable (for wired connection)

⚡ FEATURES:
════════════

✓ Modern desktop interface
✓ USB & WiFi device connection
✓ Real-time battery monitoring
✓ Device manager
✓ Settings & quick controls
✓ No Flutter installation needed!

🔧 TROUBLESHOOTING:
═══════════════════

❌ "ADB not found" error?
   → Install Android Platform Tools
   → https://developer.android.com/studio/releases/platform-tools

❌ Device not detected?
   → Enable USB Debugging on your phone
   → Accept USB debugging authorization dialog
   → Try different USB cable/port

❌ App won't start?
   → Make sure Windows 10/11 64-bit
   → Check antivirus isn't blocking
   → Run as Administrator (if needed)
